
# Git Reference

## Daily Workflow

git status
git diff
git add
git commit
git push

## Branching

git switch -c feature/name
git switch main

## Merge

git merge branch-name

## Remote

git pull
git push

## History

git log --oneline
git log --oneline --graph --decorate --all

## Tags

git tag
git tag -a V1.0.0 -m "Release"
git push origin V1.0.0

## Troubleshooting

git status
git diff
git merge --abort
