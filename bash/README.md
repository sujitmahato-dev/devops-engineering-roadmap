# Bash Automation

This directory contains Bash scripts created during my Devops learning journey.

## Linux Health Check

'linux-health-check.sh' checks:

-- Hostname
-- Current User
-- Operating System
-- Kernel Version:
-- System uptime
-- Memory Usage
-- CPU Information:
-- Disk Usage
-- IP address
-- Listening ports

## Purpose
The goal is to automate basic Linux server health checks.
